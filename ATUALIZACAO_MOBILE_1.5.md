# Menufy Mobile 1.5

## Novidades

- barra inferior fixa estilo aplicativo;
- 5 atalhos: Início, Categorias, Produtos, Aparência e QR;
- drawer lateral continua disponível com botão Sair;
- título da página atual no cabeçalho;
- pedidos viram cards no celular;
- formulários em uma coluna;
- inputs com tamanho adequado para toque;
- QR Code adaptado a telas pequenas;
- ajustes para PWA instalada;
- suporte a safe-area do iPhone;
- cards de métricas responsivos.

## Publicar

```bash
npm install
npm run build
git add .
git commit -m "Atualiza Menufy mobile 1.5"
git push
```
